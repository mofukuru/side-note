# SideNote 中文使用指南

[English](./README.md) · [日本語](./README-ja.md)

SideNote 是一款 Obsidian 插件，可以给 Markdown 笔记中的一段文字或整篇笔记添加评论。评论集中显示在侧栏或分栏里。点击评论可以跳到正文中的对应位置，有评论的文字也会在编辑器里高亮显示。

## 快速开始

在 Obsidian 的「设置 → 第三方插件」中搜索 `SideNote`，安装后启用。按 `Ctrl/Cmd + P` 打开命令面板，可用下面的英文名称搜索命令。

| 想做什么 | 操作 |
| --- | --- |
| 给一段文字加评论 | 选中文字，右键选择 `Add comment to selection`，或从命令面板运行同名命令。 |
| 给整篇笔记加评论 | 不选中文字，右键选择 `Add note comment`。点击这类评论会跳到笔记开头。 |
| 只高亮，不写评论 | 选中文字后运行 `Highlight selection (without comment)`，之后仍可补写评论。 |
| 在侧栏查看评论 | 点击左侧工具栏的消息图标，或运行 `Open in Sidebar`。切换笔记时侧栏会随之更新。 |
| 在单独的分栏查看评论 | 运行 `Open in Split View`。 |
| 查看库里的评论 | 运行 `View all comments`，或在评论面板切换到 `All Notes`。 |

填写评论时，按 `Ctrl/Cmd + Enter` 保存，按 `Esc` 取消。如果有未保存的修改，插件会提示确认。

## 查找和管理评论

- 点击评论跳转到正文。点击正文里的高亮也可以找到对应评论。
- 双击评论，或通过 `…` 菜单选择 `Edit`，可直接编辑。编辑时可用 `Quote selection` 将选中的正文插入为引用。
- 在评论输入框键入 `[[` 可以搜索笔记并插入链接，键入 `![[` 可以插入嵌入式链接。
- 可以将图片粘贴或拖入评论输入框。图片会按照 Obsidian 的附件位置设置保存，并嵌入评论。
- 评论面板的搜索框会匹配被高亮的文字和评论正文，支持中文输入法。可在当前笔记或全部笔记的视图中搜索。
- 通过评论菜单可以修改单条高亮的颜色或删除评论，也可以折叠评论正文。
- 在 SideNote 设置中可以调整高亮的样式、颜色和透明度，选择按正文位置或创建时间排序，以及设置是否显示已解决的评论。
- 可在设置中使用 `Create Markdown Backup` 导出 Markdown 备份，并用 `Markdown comments folder` 设置备份目录。

## 移动端

在 Obsidian 移动端的编辑模式下，长按并选择要评论的文字，再点击编辑器工具栏的消息图标。找不到图标时可横向滑动工具栏。查看评论时，可从命令面板运行 `Open in Sidebar`。如果短选区难以选中，可以试着选一段稍长的文字。

## 高亮与定位

在 Obsidian 内编辑时，高亮会随正文位置变化。在高亮范围内改字时，评论会继续关联该段文字，引用也会随之更新。删除整段高亮文字或跨高亮边界编辑时，评论仍可能变成孤立评论，可在插件设置中查看和管理。

建议选取容易区分的一段文字，条件允许时至少选 10 个字符。重启 Obsidian 或从外部修改笔记后，如果原来的位置失效，重复短句可能让插件难以定位到正确的一处。
